angular.json - Contains Angular CLI workspace configuration, including project settings and build, serve, and test configurations.

tsconfig.json - Contains the base TypeScript compiler configuration for the Angular project.

tsconfig.app.json - Contains TypeScript compiler settings specifically used to compile the Angular application.

package.json - Contains project information, npm scripts, and the dependencies required by the Angular application.

src/main.ts - The main entry point of the Angular application that bootstraps the root application.

src/app/app.config.ts - Contains application-level configuration and providers for a standalone Angular application.

src/app/app.component.ts - Defines the root component of the Angular application.

src/index.html - The main HTML page containing the root HTML element where the Angular application is rendered.



Build Budgets:

maximumWarning - Specifies the bundle size at which Angular displays a warning during the build.

maximumError - Specifies the bundle size at which Angular reports a build error when the configured size limit is exceeded.
